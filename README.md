# stele-sink-cloud

Releases of `stele-sink-cloud`, the [stele](https://github.com/lictor-ai/stele) plugin that sends your project's stele log to [stele Cloud](https://app.stele.lictorlabs.com). stele Cloud shows which of your rules your team's agents follow, across every project.

This repository holds releases only.

## Install

1. Download the archive for your system from [Releases](https://github.com/lictor-ai/stele-sink-cloud/releases/latest).
2. Check it against `checksums.txt` (`sha256sum -c checksums.txt --ignore-missing`).
3. Put `stele-sink-cloud` in a folder on your `PATH`.

Then follow [stele Cloud](https://stele.lictorlabs.com/docs/cloud) in the stele docs to connect a project.
